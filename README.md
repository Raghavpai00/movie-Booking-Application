# 🎬 Movie Booking Application

A Spring Boot REST API for browsing movies/theaters/shows and booking tickets, with JWT-based auth and role-based access control (`ROLE_USER` / `ROLE_ADMIN`).

> This repo doesn't ship a README — this one was written from the actual source code.

## Features
- Register / login with JWT auth
- Role-based access (`USER`, `ADMIN`)
- Manage movies, theaters, and shows (admin-only writes)
- Create, confirm, and cancel bookings; query by user, show, or status

## Tech Stack
Java 17 · Spring Boot 3.5.4 · Spring Data JPA · Spring Security · MySQL (H2 optional) · JWT (jjwt) · Lombok · Maven

## Architecture
Layered, domain-per-package structure:
```
Controller → Service → Repository → Entity
```
Domains: `user`, `movie`, `theater`, `show`, `booking`, with `Jwt/` and `Security/` handling auth.

## Database
Schema auto-generated by Hibernate (`ddl-auto=update`). Core relationship:
```
User (1)─<Booking>─(1) Show (N)─(1) Movie
                          └─(1) Theater
```

## Key API Endpoints
| Area | Base path | Notes |
|---|---|---|
| Auth | `/api/auth` | `registerNormalUser`, `login` — public |
| Admin | `/api/admin` | `registerAdminUser` — ADMIN only |
| Movies | `/api/movies` | CRUD + search by genre/language/title |
| Theaters | `/api/theater` | CRUD + search by location |
| Shows | `/api/show` | create/list/update/delete |
| Bookings | `/api/booking` | create, confirm, cancel, query |

Full endpoint list, request/response bodies, and Postman examples available on request.

## JWT Auth (quick version)
1. Register → log in → get `jwtToken`
2. Send `Authorization: Bearer <token>` on protected requests
3. `/api/auth/**` is public; `/api/admin/**` needs `ROLE_ADMIN`; everything else needs a valid token

Config keys: `jwt.secret`, `jwt.expiration` (in `application.properties`) — replace the checked-in secret before deploying anywhere real.

## Installation

```bash
git clone https://github.com/Raghavpai00/movie-Booking-Application.git
cd movie-Booking-Application
```

Set up MySQL to match `application.properties` (or switch to the commented-out H2 config for a no-setup option), then:

```bash
./mvnw spring-boot:run      # macOS/Linux
mvnw.cmd spring-boot:run    # Windows
```
App runs at `http://localhost:8080`.
